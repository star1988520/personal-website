# 间距系统提案

目标：建立可重复使用的节拍，让页面“有呼吸但不拖沓”，并减少 58、65、70、90、110、130、140px 等孤立数值。

## 基础刻度

```css
:root {
  --space-1: 8px;
  --space-2: 16px;
  --space-3: 24px;
  --space-4: 32px;
  --space-5: 48px;
  --space-6: 64px;
  --space-7: 88px;
  --space-8: 112px;
  --space-9: 144px;
}
```

`--space-9` 只用于首页首个大型叙事区或特殊视觉场景，不作为普通区块默认值。

## 推荐规则

| 场景 | 桌面 | 平板 | 手机 |
|---|---:|---:|---:|
| 页面左右安全边距 | 6vw，最大内容 1120px | 6vw | 24px |
| 页面首屏到首个内容区 | 88–112px | 72–88px | 56–64px |
| 普通区块上下 | 88px | 72px | 56px |
| 大型叙事区上下 | 112px | 88px | 64–72px |
| 标题到正文 | 24–32px | 24px | 16–24px |
| 标题区到卡片组 | 40–48px | 32–40px | 24–32px |
| 卡片内边距 | 40–48px | 32–40px | 24–30px |
| 卡片间距 | 24–32px | 24px | 20–24px |

## 五页应用方向

- 首页：将普通区块统一到 88/72/56px；肖像介绍可保留 112/88/64px 的较大节奏。
- 视频：横幅下、筛选下、卡片区下方分别归入 48、40、88px，不再混用 58/45/70px。
- 关于：近日生活与时间轴之间统一为 88px；卡片内部维持 24–32px，避免外松内紧。
- 产品：保留 500px 动画高度；动画到目录用 64–72px，目录到卡片维持约 24–30px。
- 联系：完成态标题区到内容区使用 72–88px；平板单栏时联系信息到表单使用 64px。

## 特殊构图例外

- 产品页初始动画的负空间属于演出，不纳入普通区块间距。
- 联系页羽毛笔书写区高度由轨迹决定，不直接套用普通标题容器高度。
- 首页视频首屏为全视口媒体，固定视频长截图的拼接白带不是页面间距。

## 实施原则

先增加变量，不立即删除旧值；按页面逐步替换并在 1440/768/390 三档复测。局部偏差优先选相邻刻度，只有动画轨迹或图片比例确实需要时才保留特殊值。
