# 修改优先级

本文件只定义下一阶段顺序，本轮未修改网页代码。

## 必须修（P0）

1. 建立全局字体变量并统一页面主标题、区块标题、卡片标题三个层级。
2. 将普通区块间距收敛到 56/72/88px 响应式节拍，大型叙事区使用 64/88/112px。
3. 合并 `.main-nav a`、`.film-description` 等重复字号覆盖，避免新页面继续继承不确定值。
4. 统一 800px 与 650px 断点职责：800px 负责布局换列，650px 只负责手机字号与紧凑间距。
5. 重点复测 390px 下产品、联系长标题及目录栏的安全边距。

## 建议修（P1）

1. 视频页“想看更多内容？”降为标准区块标题，避免与页面标题同权。
2. 关于页“近日生活”“斯达星迹”使用同一层级，翻书“敬请期待”保留场景例外。
3. 产品卡标题从最高 52px 调整到 38–44px，手机端 30–36px。
4. 联系页“让我们开始一场谈话”降至标准区块标题，并统一平板单栏间距。
5. 首页星语标题在手机端降至 24–26px，与 34–40px 区块标题拉开差距。

## 保留不动

- 文案、图片、视频、交互逻辑和动画时间轴。
- 古典衬线字体、纸张底色、暖棕与古金色系。
- 产品汇聚、羽毛笔书写、翻书、胶片横幅等特色构图。
- 产品目录短线与双卡结构。

## 推荐实施顺序

1. 全局 CSS 变量与重复规则整理。
2. 首页：最长页面，最能验证新间距节拍。
3. 关于页：层级差异最多。
4. 视频页：主标题与末尾 CTA 权重。
5. 产品页与联系页：最后微调，避免破坏成熟动画。

每一步都在 1440/768/390 三档完成截图对比后再进入下一页。
