# 字体层级提案

目标：让用户跨五个栏目时，始终能凭字号判断信息层级，同时保留古典衬线字体的画册感。

## 推荐阶梯

| 层级 | 桌面 | 平板 | 手机 | 用途 |
|---|---:|---:|---:|---|
| 辅助标记 XS | 10px | 10px | 9px | 编号、状态、目录索引 |
| 英文眉题 / 标签 | 12px | 11px | 10px | `FROM THOUGHT TO FORM`、分类标签 |
| 小正文 | 14px | 14px | 14px | 时间、说明、次要元数据 |
| 正文 | 16px | 16px | 16px | 段落、表单、卡片描述 |
| 引导正文 | 20px | 19px | 18px | 首屏简介、重要副标题 |
| 卡片标题 | 38–44px | 36–40px | 30–36px | 产品卡、大型内容卡 |
| 区块标题 | 48–54px | 42–48px | 34–40px | “视频专区”“近日生活”“让我们开始一场谈话” |
| 页面主标题 | 80–92px | 64–76px | 44–54px | 内页唯一主标题 |

## 可转换为 CSS 的建议

```css
:root {
  --type-xs: 10px;
  --type-eyebrow: 12px;
  --type-sm: 14px;
  --type-body: 16px;
  --type-lead: clamp(18px, 1.6vw, 20px);
  --type-card-title: clamp(34px, 3.5vw, 44px);
  --type-section-title: clamp(38px, 4.2vw, 54px);
  --type-page-title: clamp(52px, 7vw, 92px);
}
```

手机断点建议将页面主标题上限压到 52px；超过 7 个汉字或需要两行时使用 44–48px。

## 页面映射建议

- 视频“数字纪念馆”、产品“把想法，做出来”、联系“从一封信开始”：页面主标题。
- 首页“视频专区”“留下一句话”、关于“近日生活”“斯达星迹”、联系“让我们开始一场谈话”：区块标题。
- 视频“想看更多内容？”：区块标题，不应接近页面主标题。
- 产品“今天星星说什么？”与“敬请期待”：卡片标题。
- 关于翻书背面的“敬请期待”：允许作为场景标题例外，但手机端不超过 48px。

## 行高与字距

- 页面主标题：`line-height: 1.0–1.08`，中文负字距不超过 `-0.02em`。
- 区块标题：`line-height: 1.12–1.2`。
- 卡片标题：`line-height: 1.15–1.25`。
- 正文：`line-height: 1.75–1.9`；手机端长段落建议 1.75。
- 英文眉题：`letter-spacing: .22em–.3em`，手机端适当降至 `.18em–.24em`。

## 不建议改变

- 保留现有展示衬线与正文字体组合。
- 不统一所有特殊动画标题的显现方式，只统一最终字号。
- 不把正文缩到 15px 以下；网站的优雅感应来自秩序和留白，不来自小字。
